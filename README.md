# PW Opener 1.1.4

PW Opener — удобная база персонажей и мультизапуск окон **Perfect World**.

## Возможности

- Несколько серверов и персонажей в одном списке.
- Отметил нужных персонажей — нажал «ЗАПУСТИТЬ», и окна открываются по очереди.
- Шаблоны запуска: «Фарм», «Все окна» и любые свои наборы.
- Импорт персонажей из bat-файлов: логин, пароль и ник подтягиваются из строк запуска клиента.
- Переименование окна клиента в формат «Никнейм: НазваниеСервера» — по желанию, по умолчанию выключено.
- Видно, какие персонажи уже запущены; окно можно развернуть или закрыть.
- Автоматическое сканирование открытых окон раз в минуту.
- Сворачивание в трей и быстрый доступ к запущенным окнам.
- Автозапуск вместе с Windows.
- Защита от второго запуска: повторный запуск разворачивает уже открытое окно.
- Экспорт и импорт серверов, персонажей и шаблонов в зашифрованный файл.
- Мастер-пароль для защиты экспортируемых данных.
- Автоматическая проверка обновлений.

## Установка

1. Распакуйте архив в обычную папку.
2. Запустите `PWOpener.exe`.

Папку `libs` нужно оставить рядом с программой — в ней находятся компоненты, без которых программа не запустится.

Не запускайте PW Opener из папок с ограниченными правами или из песочницы: клиент игры может работать с ограничениями и зависать на экране выбора персонажа.

## Данные

Серверы, персонажи, шаблоны и настройки хранятся в `%APPDATA%\PWOpener`.
Пароли персонажей защищены средствами Windows и привязаны к текущей учётной записи.

При переносе на другой компьютер пароли нужно ввести заново — либо использовать экспорт/импорт с мастер-паролем.

## Мастер-пароль

Мастер-пароль нужен для экспорта и импорта данных.

- Минимум 8 символов.
- При экспорте пароль запрашивается каждый раз.
- При импорте нужен пароль того архива, под которым его сохраняли.
- Пароль не хранится в открытом виде.
- Восстановить забытый мастер-пароль невозможно.

## Обновления

Программа сама проверяет новые стабильные версии и предлагает обновиться.
Можно проверить вручную: **Настройки → Обновления → Проверить обновления**.
